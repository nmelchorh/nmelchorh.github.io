NM Personal Automation

NM Personal Automation is a private, single-user setup that connects the owner's own Google account to the owner's own tools: an AI coding assistant (Claude Code) on the owner's computer, which manages the owner's Google Tasks lists, and a Home Assistant server in the owner's home, which shows the owner's Google data (for example, the owner's calendar) at home.

It is not a public service. It has one user, the owner, and no one else signs in to it.
