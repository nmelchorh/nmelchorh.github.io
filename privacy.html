Privacy policy

NM Personal Automation. Last updated: 13 October 2026.

Who uses it

This app has a single user: its owner. It is not offered to the public.

What Google data it accesses, and how it is used

Only the owner's own Google data, and only after the owner signs in and consents:

  • Google Tasks (https://www.googleapis.com/auth/tasks): the owner's AI coding assistant (Claude Code) reads, creates and updates the owner's tasks when the owner asks it to. Task content is then processed by the assistant's provider, Anthropic, as part of the owner's conversation, and may remain in the owner's conversation history. The owner's Home Assistant server only renews this authorization; it does not read or store task content.
  • Home Assistant Google integration: the owner's Home Assistant server reads the Google data the owner connects to it (for example, the owner's calendar) to show it at home. That data stays on the owner's Home Assistant server.

The data is not sold, not used for advertising, and not shared with anyone else.

Storage

Authorization tokens are stored only on the owner's own computer and Home Assistant server.

Google API Services User Data Policy

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
